# Contributing to SmartCareer AI

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/YOUR_USERNAME/smartcareer-ai.git`
3. Create a feature branch: `git checkout -b feature/your-feature-name`
4. Make your changes
5. Commit: `git commit -m "Add your feature"`
6. Push: `git push origin feature/your-feature-name`
7. Open a Pull Request

## Code Standards

- Follow ES6+ syntax for JavaScript
- Use meaningful variable names
- Add comments for complex logic
- Keep functions small and focused
- Write descriptive commit messages

## Backend Development

- Use Express.js best practices
- Validate all inputs
- Handle errors gracefully
- Use environment variables for config
- Add API documentation

## Frontend Development

- Use functional components with hooks
- Follow React best practices
- Keep components reusable
- Use proper state management
- Add loading and error states

## Testing

- Test your changes locally
- Test API endpoints with cURL
- Verify UI responsiveness
- Check browser console for errors

## Pull Request Process

1. Update documentation if needed
2. Add comments to complex code
3. Ensure code follows project standards
4. Link related issues
5. Describe your changes in the PR

## Reporting Issues

- Check existing issues first
- Provide detailed description
- Include steps to reproduce
- Attach screenshots if applicable

## Questions?

Open an issue or reach out to the maintainers!
